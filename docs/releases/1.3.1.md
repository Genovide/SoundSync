# SoundSync 1.3.1

## Живые фоны всего приложения

- Девять анимированных фонов: северное сияние, облака, мягкое сияние, Globe, туман, тёмная вуаль, шёлк, Galaxy и световой столб.
- Выбор в «Настройки → Внешний вид → Фон приложения». Можно вернуться к обычному оформлению по обложке.
- При выбранной анимации цвета панелей и кнопок подстраиваются под сцену, а не под обложку трека.
- Ограничены разрешение и частота отрисовки, при скрытом окне анимация останавливается. Добавлены предупреждение о нагрузке, статичный запасной фон и поддержка уменьшенного движения.
- Galaxy не реагирует на движение курсора.

## Развлечения

- Новый раздел «Развлечения»: музыкальный инкогнито, апгрейдер и питомец.
- В инкогнито слушаешь пять фрагментов без названий и обложек, выбираешь впечатление, затем раскрываешь треки.
- Пластинка в закрытом конверте плавно движется при прослушивании и переворачивается в обложку после ответа.
- Аккуратные иконки сердца и разбитого сердца в итогах сеанса.

## Импорт и большие плейлисты

- Импорт коллекции Яндекс Музыки по публичной ссылке с названиями, исполнителями, альбомами и длительностью.
- Поиск при переносе может продолжаться в фоне; окно можно скрыть и открыть снова по индикатору прогресса.
- Исправлены потеря найденных треков при сохранении большого плейлиста, пустое отображение и расхождение количества треков.
- Списки выводятся порциями, а поиск и очередь воспроизведения работают со всем плейлистом.
- Импорт лайков профиля SoundCloud создаёт отдельный плейлист с редактируемым названием. Существующее «Любимое» не меняется.
- Исправлено получение потока для импортированных треков с устаревшими данными SoundCloud.

## Интерфейс

- Один блок «Что включим?» на главной: «Моя музыка», «Любимое» и «Моя волна».
- Поиск расположен внутри страниц, единое оформление поля и кнопки «Найти».
- Обновлены расположение элементов страницы плейлистов и поведение интерфейса в узких окнах.

## Установка

Установщик Windows x64 и DMG для macOS Apple Silicon — для полной установки. Update ZIP — для обновления существующего SoundSync. Музыка, плейлисты и настройки сохраняются.
